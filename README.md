# NodeVideoEffects

YMM4用の、ノードで加工をする映像エフェクトプラグイン

## 概要
このプラグインは、映像エフェクト「NodeVideoEffects」を追加します。

この映像エフェクトでは、ノードを接続することで画像を、その接続の順に連鎖的に加工することができます。

### ノードとは
ノードは、1つ1つが固有の働きをもつ機械のようなものです。

ノードには「端子」と呼ばれる小さな丸が端についています。左側についているものが「入力端子」、右側が「出力端子」です。

この端子から「接続線」を引き延ばして別のノードの別の側の端子につなげると、この2つの端子の間で、出力から入力へデータが送られます。

ノードは、各入力端子のデータを基に出力端子から送り出すデータを作り出します。

ちなみに、入力端子に何もつなげずに、自分でデータを設定することもできます。

たくさん組み合わせると、YMM4だけではできない、複雑な表現ができます。

## インストール
最新リリース（Latest）の.ymmeファイルをダウンロードし、実行してください。
